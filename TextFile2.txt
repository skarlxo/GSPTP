게임 명세서
장르: 2~4인 협동 탑다운 슈터
목표: 적 웨이브를 막고 기지를 지키며 마지막 보스까지 처치
주요 기능: 이동, 공격, 부활, 아이템 획득, 역할 분담, 웨이브 진행
승리: 마지막 웨이브 클리어
패배: 기지 체력 0 또는 전원 전투 불능


서버 기능 정의 명세서
| 기능         | 서버 역할                |
| ------------ | -------------------- |
| 접속         | 플레이어 확인 및 세션 생성      |
| 방 생성/입장 | 참가자 관리 및 상태 공유       |
| 이동         | 위치 검증 후 다른 플레이어에게 전송 |
| 공격         | 데미지 및 적 HP 처리        |
| 아이템       | 획득 가능 여부 확인 후 적용     |
| 부활         | 거리와 상태 확인 후 부활 처리    |
| 웨이브       | 적 생성 및 다음 웨이브 진행     |
| 재접속       | 기존 게임 상태 복구          |
| 게임 종료    | 승패/점수 처리 및 방 정리      |
